# 세온 식탁

인스타그램에서 저장한 아이 밥 레시피를 구글 시트에 모아 두고, 웹사이트에서 재료나 요리 이름으로 찾아보는 페이지입니다.
레시피는 구글 시트에서 고치고, 웹사이트는 시트를 읽어서 보여 주기만 합니다. 로그인은 필요 없습니다.

## 1. 구글 시트 만들기

1. [Google Sheets](https://sheets.google.com)에서 새 스프레드시트를 만듭니다.
2. **파일 → 가져오기 → 업로드**로 `recipes-template.csv`를 올리고 "현재 시트 바꾸기"를 고릅니다.
   (직접 만들 경우 첫 줄에 아래 제목을 적습니다.)

   | 요리 이름 | 종류 | 재료 | 만드는 법 | 인스타그램 링크 | 아이가 잘 먹음 |
   |---|---|---|---|---|---|
   | 두부 채소 동그랑땡 | 반찬 | 두부, 당근, 애호박, 계란 | 1. 두부 물기 짜기 … | https://www.instagram.com/reel/… | O |

   - **요리 이름**만 꼭 적으면 되고, 나머지는 비워도 됩니다.
   - **재료**는 쉼표(,)로 나눠 적습니다. 재료로 검색할 때 이 칸을 봅니다.
   - **종류**는 밥·죽, 국·찌개, 반찬, 면, 간식, 기타 중에 적으면 화면 위 버튼으로 나뉩니다. 다른 이름을 써도 됩니다.
   - **사진**에는 음식 사진 주소를 넣습니다. 구글 드라이브에 사진을 올리고 "링크가 있는 모든 사용자"로 공유한 링크를 붙여넣으면 됩니다. 비워 두면 그릇 그림이 대신 나옵니다. 인스타그램 사진 주소는 며칠 지나면 막히므로 쓰지 마세요.
   - **묶음**은 게시물 하나에 레시피가 여러 개 들어 있을 때 씁니다. 아래 "여러 요리가 담긴 게시물" 참고.
   - **아이가 잘 먹음**에 아무 글자(O, ⭐ 등)나 적으면 목록 위쪽에 먼저 나옵니다.
3. 오른쪽 위 **공유 → 일반 액세스 → "링크가 있는 모든 사용자" (뷰어)**로 바꾸고 **링크 복사**를 누릅니다.

### 여러 요리가 담긴 게시물

"돌 아기 돼지고기 반찬 5가지"처럼 사진을 넘기며 보는 게시물은 **요리마다 한 줄씩** 적습니다.

| 요리 이름 | 인스타그램 링크 | 묶음 |
|---|---|---|
| 돼지고기 애호박볶음 | https://www.instagram.com/p/ABC123/?img_index=2 | 돌 아기 돼지고기 반찬 5가지 |
| 돼지고기 두부조림 | https://www.instagram.com/p/ABC123/?img_index=3 | 돌 아기 돼지고기 반찬 5가지 |

- **묶음**에는 같은 글자를 똑같이 적습니다. 사이트가 시트 순서대로 "5개 중 2번째"처럼 번호를 붙이고, 레시피 화면 아래에 같은 묶음의 다른 레시피를 보여 줍니다.
- 묶음 이름으로도 검색됩니다.
- 링크 끝에 `?img_index=번호`를 붙이면 그 번째 사진이 바로 열립니다. 복사한 링크에 이미 `?…`가 붙어 있으면 그 부분을 지우고 붙이세요. 인스타그램 앱으로 열리면 첫 사진부터 보일 수 있습니다.

### 지금 연결된 시트

`config.js`에는 구글 시트 **세온-식탁-레시피**가 연결되어 있습니다. 사이트는 첫 줄 제목을 보고 칸을 찾습니다.

| 시트 칸 | 사이트에서 |
|---|---|
| 음식 이름 | 카드 제목 |
| 주재료 | 카드에 보이는 재료, 재료 버튼 |
| 재료 및 분량 | 레시피 화면의 재료 목록 |
| 만드는 방법 | 만드는 법 |
| 할머니 메모 | 노란 메모 상자 |
| 인스타 링크 / 사진 URL | 인스타 버튼 / 카드 사진 |
| 분류 | 종류 버튼 ("미분류"는 "기타"로) |
| 조리 시간(분) | ⏱ 20분 |
| 묶음 | "5개 중 2번째"처럼 묶어서 표시 |
| 출처 | 카드와 레시피 화면에 "출처 · @아이디"로 표시 (@아이디면 인스타 프로필로 연결) |
| 잘 먹음 | 사이트의 하트(♥) 버튼으로 O가 적히고 지워집니다. 직접 O를 적어도 됩니다. |
| 공개 여부 | **"비공개"면 사이트에 안 보입니다.** "공개"나 빈칸이면 보입니다. |

## 2. 시트 주소 연결하기

`config.js`의 `sheetUrl`에 복사한 주소를 붙여넣습니다.

```js
window.RECIPE_BOX = {
  sheetUrl: "https://docs.google.com/spreadsheets/d/…/edit?usp=sharing"
};
```

아기가 태어난 달을 `babyBirth: "2025-08"`처럼 적으면 오른쪽 위에 "우리 아기 ○개월"이 저절로 계산되어 나옵니다.

GitHub 웹사이트에서 `config.js`를 열고 연필 버튼으로 고친 뒤 **Commit changes**를 누르면 1~2분 뒤 사이트에 반영됩니다.

## 3. 할머니 폰에 넣기

- 사이트 주소를 카카오톡 등으로 보내 드립니다.
- 아이폰(사파리): 공유 버튼 → **홈 화면에 추가**
- 갤럭시(삼성 인터넷·크롬): 메뉴 → **홈 화면에 추가**

그러면 앱처럼 아이콘을 눌러 바로 열 수 있습니다.

## 알아 둘 점

- 시트를 고치면 사이트를 다시 열거나 **↻ 새로 불러오기**를 누를 때 반영됩니다.
- 시트 링크를 아는 사람은 누구나 레시피를 볼 수 있습니다. 개인 정보는 적지 마세요.
- 인터넷이 끊겨도 마지막으로 불러온 레시피는 그 폰에서 계속 보입니다.

- `photos/` 폴더의 사진은 레시피 출처(시트 '출처' 칸)의 것입니다. 원작자가 요청하면 바로 지워 주세요.
- 하트 버튼은 구글 계정(teahill1111@gmail.com)의 Apps Script 프로젝트 `seon-table-heart`가 시트에 기록합니다. 이 프로그램은 '잘 먹음' 칸만 바꿉니다. 주소는 `config.js`의 `likeUrl`에 있고, 비우면 하트 버튼이 숨겨집니다.
